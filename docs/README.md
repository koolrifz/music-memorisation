# Docs

Design briefs and planning notes for Kool Riffs live in a separate, private repo: [`koolrifz/kool-riffs-docs`](https://github.com/koolrifz/kool-riffs-docs). This repo has to stay public for free GitHub Pages hosting, so planning content that doesn't need to be world-readable lives there instead.

The exceptions are the plans that describe this repo's own code:

- [`language-files-plan.md`](language-files-plan.md): how on-screen words, voice lines, sounds and pictures move out of the HTML and JS into language and content files.
- [`start-building.md`](start-building.md): for Rob. How to start the build in Claude Code or in VS Code with Copilot, with prompts ready to paste.
- [`value-smash-build-guide.md`](value-smash-build-guide.md): the step-by-step build spec for Value Smash Phase 0 and Phase 1. Works for Claude Code or GitHub Copilot.
- `project-knowledge.md`: generated by `tools/build-project-knowledge.py`. Don't edit it by hand.
